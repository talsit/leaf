# leaf

## [NEON SKYHOOK](neon-skyhook/)

An 80s-neon helicopter rescue game: fly a chopper through a night-time city, pick people up with your skid, and carry the swinging human chain to a hospital roof.

**Play:** https://talsit.github.io/leaf/neon-skyhook/

Single self-contained `index.html` (three.js loaded from a CDN). Earlier versions are kept as `index00.html`, `index01.html`, …
